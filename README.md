# 🔢 Even or Odd Checker

A simple Python program that checks whether a given number is **even or odd**.

## 🚀 Features

* Takes a number from the user
* Checks whether the number is even or odd
* Displays the result clearly
* Beginner-friendly Python project

## 🧠 How It Works

The program uses the **modulo operator `%`** to find the remainder after dividing a number by 2.

* If the remainder is `0`, the number is **even**.
* Otherwise, the number is **odd**.

Example:

```python
10 % 2 == 0  # Even
7 % 2 != 0   # Odd
```
